HARNESSING / CLAUDE CODE

From zero to graph engineering on AI agents — for people who use them.

A free, open-source course. 119 lessons across 19 phases. MCP, hooks, plugins, worktree isolation, dynamic workflows, harness engineering, task graphs.

Every abstraction in Claude Code resolves to something you can reason about, break, and rebuild. This course teaches the mechanism — not the prompt.

Why this course exists

Most agentic tooling is taught in two broken ways: as a list of features, or as prompts to copy. Neither teaches the mechanism. The same fear — losing work to an agent run — drives both failures. The fix is to know what the agent is doing. This course is that.

Teaching it to yourself, with an agent

This repo is designed to be pointed at an AI agent. The MCP server and REST API are the agent entry points. Four skills, each invoked deliberately by the learner:

CommandDoes
/teach-meTeach one lesson, at the learner's actual level
/run-moduleStart or grade a practice module
/where-am-iWhat's demonstrated, what's next
/write-lessonAuthor a new lesson

Authoring the corpus itself is also a workflow: node scripts/dynamic-workflow.mjs reports what is missing, authors it in isolated worktrees, validates, and rebuilds this site. See Developer.
