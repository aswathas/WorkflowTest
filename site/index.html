HARNESSING / CLAUDE CODE

From zero to graph engineering on AI agents — for people who use them.

A free, open-source course. 119 lessons across 20 phases. MCP, hooks, plugins, worktree isolation, dynamic workflows, harness engineering, task graphs.

Every abstraction in Claude Code resolves to something you can reason about, break, and rebuild. This course teaches the mechanism — not the prompt.

Why this course exists

Most agentic tooling is taught in two broken ways: as a list of features, or as prompts to copy. Neither teaches the mechanism. The same fear — losing work to an agent run — drives both failures. The fix is to know what the agent is doing. This course is that.

Teaching it to yourself, with an agent

This repo is designed to be pointed at an AI agent. The MCP server and REST API are the agent entry points. Four skills, each invoked deliberately by the learner:

CommandDoes
/teach-meTeach one lesson, at the learner's actual level

What you will learn

  • Phase 0 — Setup & Tooling. Tools shape thinking. Five lessons on environment, git, terminal, editor, debugging.
  • Phase 3 — Models & Families. Open-weight vs frontier, when small wins, the decision-model line.
  • Phase 4 — Claude Code. The agentic loop, sessions, permissions, settings, plan mode, checkpoints, troubleshooting.
  • Phase 5 — Skills, subagents, MCP, hooks, plugins. The extension layer.
  • Phase 8 — Memory & instructions. CLAUDE.md, AGENTS.md, rules, output styles, imports.
  • Phase 11–12 — Parallelism I & II. Five distinct names, isolation, the agentic loop's parallel version.
  • Phase 13–14 — Context & harness engineering. Context as architecture. The loop minus the intelligence.
  • Phase 15 — Graph engineering. Nodes, edges, the frontier, the critical path.
