## Primary — git (prerequisite for everything)
- Pro Git book, free online: https://git-scm.com/book/en/v2
  - Ch. 2 "Git Basics" covers commits, branches, merging
  - Ch. 10 "Git Internals" explains what a commit object *is*
- Learn Git Branching (interactive visualizer): https://learngitbranching.js.org
  - Best single resource for someone with rusty git. Live, visual, no setup.
